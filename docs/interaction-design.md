# 拾页 0.3.0 界面与交互

日期：2026-10-09。范围：登录页、剪藏页与保存反馈的存量界面深化，按用户指定的 oil-ui-pro 执行。

## 方向与约束

拾页是阅读收集工具，首屏的主动作是输入页息访问码；已登录后是确认当前文章、分类和保存。保留已有暖白纸面、用户 Logo 与深绿色方向，用宋体口号和折角纸页呼应「拾起灵感，留住好文章。」。不重新探索品牌方向或引入框架。

弹窗固定 400×600，页头固定，内容区域滚动；默认剪藏页完整显示保存和退出登录，展开预览、新分类或错误时允许向下滚动。六格访问码、原生分类选择、正文/选区/书签、标签和草稿保存继续使用原有业务链路。

## 可观察的变化

- 移除右上角设置入口、整个设置页和 API 地址输入。默认连接 `https://pagehush.yohoia.cn` 的 `/v1` 接口；后台保留旧自定义配置的兼容解析。
- 登录页保留 Logo 和中文口号，六格访问码填入时染绿、聚焦时上移，完整输入后启用主按钮。错误码轻微摇动并清空，网络故障保留输入。
- 当前文章呈现为折角纸页，剪藏方式的白色选中底板滑动到对应位置。切换方式后读取新内容，保存按钮等待内容可用。
- 新分类和剪藏预览展开有短过渡，标签、分类和标题在保存失败或弹窗重开后仍可恢复。
- 保存时纸页轻轻收拢，按钮显示真实等待状态；仅在后台确认成功后出现完成纸页与勾号。关闭弹窗仍由后台完成保存，重新打开可读取结果。
- 键盘输入、整码粘贴、退格、方向键、Command/Ctrl+Enter 保留。系统开启减少动态效果时取消位移与旋转，静态状态仍完整可用。

## 减法与范围

删除设置图标、设置文案、API 地址脚注、工作台服务地址与重复登录副标题。页头用简短连接状态交代当前状态。保持登录与最长时限合并成一行，标签恢复逗号分隔提示；保存失败不展示数据库术语，明确内容已保留。保留分类、标签可选说明、正文保留范围与草稿说明，它们帮助用户判断保存内容和结果。

本轮未修改页息服务、部署流程或剪藏 API，未增加截图、资源上传、查重、PDF/Gmail 功能；它们与当前界面任务无关。

## 独立评审与验证

完成一轮只读、隔离的存量界面评审，不打分。评审查看改前/改后、200% 细节、展开与失败状态、三组动效阶段图；没有发现必须修复的视觉阻断、越界或动效缺失。三项可选建议全部采纳：明确标签分隔规则、用可理解的保存失败文案、合并保持登录时限。采纳后主 Agent 重新取证并核对实际画面。

额外修正错误提示的滚动：只调整正文区域，并给底部留空；根页面不参与滚动。检查脚本验证默认保存和退出完整可见，错误后页头仍在 y=0、窗口 scrollY=0。预览收起和减少动态效果等异步检查等待可观察的结束状态，不用短固定延时判断。

集成检查使用临时 Chromium 配置加载实际 MV3 扩展，连接隔离 API，验证后台、内容脚本与弹窗，不使用现有浏览器账号。覆盖语法与 manifest、线上默认、六格输入、分类读取、三种剪藏内容、失败保留及重开恢复、保存结果读回与短地址、后台保存和防重复、登录过期、键盘及减少动态效果；不运行生产构建或其他项目全量测试。

400×600 界面阶段最终版本连续三次检查：第 1 次通过、第 2 次通过、第 3 次通过。日志为 `evidence/interaction-check-1.log`、`interaction-check-2.log`、`interaction-check-3.log`。每次保存 6 篇隔离模拟草稿，不向生产服务写入。后续根据用户提供的印象笔记截图改为网页右侧全高面板，另做面板入口和尺寸验证。
