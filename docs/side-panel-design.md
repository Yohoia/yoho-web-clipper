# 拾页 0.3.1 右侧面板

日期：2026-10-09。按用户最新提供的印象笔记截图，将剪藏工具从工具栏固定弹窗改为当前网页右侧、接近内容区全高的面板。保留本轮 oil-ui-pro 已完成的登录、剪藏与保存交互。

## 参考与方案

已只读核对 clipper01 的 `TopFrames.css`：工具 iframe 固定在页面右侧，上方、右侧为 12px，使用高层级定位；`ContentFrame.css` 的 `.ClipperContainer`、关闭按钮及内部滚动；`content.js` 中 `ContentFrame.html` 的 iframe 载入与尺寸更新逻辑。

仅借鉴网页右侧 iframe 承载和边距。拾页继续使用自己的 Logo、暖白纸面、深绿色控件与中文口号，没有复制官方 bundle、配色或图形。与原网页同时可见，适合用户对照文章确认剪藏。

当前默认宽 400px；顶部、底部、右侧各 12px；面板外部高度 = 浏览器网页内容区高度 − 24px。边框 1px、圆角 12px、轻阴影；窗口不足宽时面板宽 = 视口宽 − 24px。面板不改变原网页宽度，不锁原网页滚动。

登录内容随可用高度居中，六格输入仍是唯一主要输入。剪藏页从文章纸页向下安排方式、分类、标签和预览，保存区域在底部。页头固定，正文承担滚动；较矮窗口允许纵向滚动，不缩小输入控件来强行塞满。

## 入口与状态

工具栏点击 → 当前网页右侧面板 → 未登录输入访问码 / 已登录读取源网页与分类 → 保存草稿 → 完成纸页与打开页息。

- 右上角「×」、Esc、再次点击工具栏关闭；重开恢复当前网页的未保存输入和保存结果。
- 内部选择框使用 Esc 时保留原生选择行为；其他控件中的 Esc 可关闭面板。
- 当前网页从后台受信任消息的 `sender.tab` 确认，不依赖面板打开后哪个标签页处于活跃状态。
- 源网页样式由 Shadow DOM 和扩展 iframe 隔离；采集排除自身 UI。关闭恢复先前焦点；保存继续由后台完成。
- Chrome 内部页面和扩展商店无法注入时，工具栏标记和提示说明应打开普通网页。

Chrome 消息、内容脚本与资源声明参考：[Chrome 官方内容脚本说明](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)、[消息说明](https://developer.chrome.com/docs/extensions/develop/concepts/messaging)。本轮未新增生产 API、图片上传或高级剪藏类型。

## 评审与验证

完成存量界面的独立只读视觉评审，不打分。第一轮核对参考、响应式、200% 细节与三处动效；指出单独面板截图的失败/等待状态有页头裁切，并建议删掉重复的登录页头说明、缩短成功交接的空白。

采纳文案删减和成功过渡改进后，补拍实际桌面父页面里的等待/失败流程，增加 900×640 失败截图和嵌入 iframe 的页头坐标检查。第二轮复核结论：等待、失败和成功中的 Logo、名称与关闭按钮完整且在同一位置，较矮窗口底部操作与错误完整可见，成功交接不再出现完全空白帧；没有仍必须修复的视觉问题。该结论只支持画面与动效，不扩大到线上功能。

最终版本连续三次隔离检查：第 1 次通过、第 2 次通过、第 3 次通过；记录为 `evidence/side-panel-check-1.log`、`side-panel-check-2.log`、`side-panel-check-3.log`。每次创建 6 篇模拟草稿，没有生产写入。先前 400×600 界面阶段也已独立评审并连续三次通过。

新增实际 MV3 嵌入面板检查：工具栏监听与入口声明、脚本注入、真实扩展 iframe、12px 边距、四种窗口尺寸、窄屏无横向溢出、源网页绑定、分类/内容读取、关闭按钮、Esc、工具栏收起、重开恢复标签。隔离检查注入相同面板脚本；真实工具栏点击另在用户当前 Chrome 完成，已确认 0.3.1 全高登录界面与关闭入口可见。

验证覆盖语法、manifest、默认线上地址、六格访问码、三种剪藏内容、标签/分类/草稿恢复、后台保存、防重复、短地址、键盘与减少动态效果。使用隔离 API，不向线上写入文章，不运行生产构建或其他项目全量测试。

本轮删除设置入口、地址输入及重复说明，包括登录右上角「页息剪藏工具」；保留已经收敛的中文文案与有用的草稿说明。未部署页息服务；没有增加全页、截图、资源上传、查重或 PDF/Gmail 功能，因为它们不属于当前界面任务。
