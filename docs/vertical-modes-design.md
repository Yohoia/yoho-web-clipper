# 纵向剪藏方式列表

日期：2026-10-09；扩展 0.4.2，使用 oil-ui-pro 0.16.6。用户提供印象笔记截图，明确采用左图标、文字名称、选中行浅色背景及右侧勾号的纵向列表。

后续尺寸更新：0.4.3 将整体收紧至 340px 并统一字体与控件，见 [当前比例](compact-ui-design.md)。下文保留 0.4.2 的设计记录。

## 方向与实现

组件回答「我要保存网页的哪一部分」。六种方式直接可见，不增加下拉或展开步骤。当前选择由整行背景和右侧勾号共同说明；切换仍重新读取对应内容。保留网页正文、整个网页、纯文字、选中内容、书签、屏幕截图，未将现有纯文字功能改名为印象笔记的「隐藏广告」。

只读参考 `/Users/yohoia/Desktop/clipper01/ContentFrame.css` 第 67–124 行：`.listItem` 为 32px 高，`.listItemWithIcon` 用左侧图标与 `margin-left: auto` 的右侧勾号。亮色变量第 3225–3228 行定义浅灰选中背景和绿色勾号。拾页使用自己的 SVG、纸白和深绿，不复制官方图标或打包代码，不修改参考目录。

正式 `popup.html` 每项使用原 radio 和标签，附加不可读出的装饰勾号；`popup.css` 改为单列 32px 行、22px 左图标、14px 名称、20px 右勾号、直角浅色选中底；`popup.js` 保留单一选中索引，移除原三列/两排坐标。方向键和焦点环可用，保存期间沿用禁用状态。

较矮窗口的中间正文滚动，标题、分类、标签均可访问；页头与保存底栏固定。单行标题、线上地址、六格登录、分类菜单、签条、权限及 API 均沿用。表单默认区块间距从 20px 收紧为 14px，700px 以下仍为 12px。

此前四种紧凑呈现保留为历史原型，当前正式扩展已直接采用本列表，不再等待用户选编号。历史预览样式隔离，避免新勾号混入旧方案。
