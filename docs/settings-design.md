# 拾页：设置与切换稳定性

日期：2026-10-10 · 版本：0.5.0

这是历史设计记录。0.5.1 按用户要求精简为只读关于页，当前入口与证据见 [关于页记录](about-design.md)。

用户任务：切换剪藏方式时保持整个面板稳定，去除左下角草稿提示，以设置齿轮打开独立设置页。沿用用户已确定的暖白纸面、绿色控件、线条图标、直角内容框和 340px 全高右侧面板；设置是工具偏好页，主要动作是直接选择并自动保存，不重新探索视觉方向。

## 参考与范围

只读检查了桌面 `clipper01/OptionsFrame.html`、`OptionsFrame.css`、`OptionsFrame.js` 与 `_locales/zh_CN/messages.json`。参考中的通用/快捷键分组、默认方式、最近使用的目标分类、剪藏完成后的行为和快捷键启用适合当前产品。用自有 HTML/CSS/JS 实现，没有复制印象笔记 bundle、账户体系或官方图形。

设置页复用面板的 Helvetica Neue / Lucida Grande / PingFang SC 字体栈、暖白与绿色变量。桌面左侧导航、右侧设置内容；390px 窄屏改为三项横向导航和两列选择。用户来这里调整剪藏偏好，选择名称和当前状态是信息主角；没有加装饰图片或另一套主题。

当前实现：

- 默认剪藏方式：六种实际支持的方式，或沿用上次。仅新网页应用默认值，已有草稿优先。默认选区但原网页没有选中文字时回到正文。
- 默认保存分类：最近使用，或优先「学习」。已有草稿的分类优先，仍可在剪藏页手动改选。
- 剪藏完成后：显示结果、在页息打开文章、收起面板。恢复已有成功页不会再次自动打开或收起。
- 快捷键：可关闭 Command / Ctrl + Enter 剪藏；方向键、Esc 与标签确认保留。页面说明操作条件。
- 减少动态效果：同步作用于设置页、剪藏页和面板入场；系统减少动态效果同样生效。
- 关于：版本、保存位置、标签数量、打开页息。

设置齿轮位于左下角，退出登录仍在右侧。点击一次进入独立 Chrome 设置标签页；选择后自动保存，无需另点提交。使用 [Chrome options page](https://developer.chrome.com/docs/extensions/develop/ui/options-page) 和 [runtime.openOptionsPage](https://developer.chrome.com/docs/extensions/reference/api/runtime#method-openOptionsPage)；服务地址仍默认线上页息，不增加手填 API 项。

未加入参考扩展的智能分类、全局快捷键重映射、截图标注等未支持能力，避免选项与实际行为脱节。设置恢复默认仅影响偏好，不清除访问凭证或草稿；设置页没有加入后台受信任消息白名单，认证与保存继续由原后台完成。

## 稳定性与失败状态

原切换流程先清空采集显示，再重新读取，说明文字的高度也随方式变化。现在保留已有标题与来源直到最新请求完成，说明区预留两行，并关闭内容区的自动滚动锚定。采集开始即禁用剪藏，避免刷新期间保存上一种方式的内容；连续切换仍只接收最后一次请求的结果。

设置修改串行保存，快速连续修改只由最新结果更新反馈。保存失败保留选择与所在分类，提示重新保存；初次读取失败禁用表单并提供重新读取。成功后刷新可读回偏好。恢复默认不影响当前登录与已有草稿。

删除的文字：面板左下角「保存为草稿，随时继续编辑」；设置页初稿中的「让每次拾页，都更顺手」「少一点点击，多一点顺手」；关于页重复口号。窄屏隐藏独立「设置」视觉标题，保留可访问标题，导航下只显示当前分类名称。登录页的品牌口号保留。

## 实际视觉与动效证据

截图和动效均由 oil-ui-pro `shoot.mjs` 生成，已查看实际画面。设置预览使用浏览器专用存储夹具，生产扩展不加载模拟脚本；预览不会写线上数据。

- `evidence/settings-default/`、`settings-shortcuts/`、`settings-about/`：1280×900 与 390×844 三类页。
- `evidence/settings-narrow-full/page-@2x.png`：390px 窄屏全页两倍细节，检查页尾与整页节奏。
- `evidence/settings-error/page-@2x.png`：实际修改后保存失败，当前选择保留，反馈及重试可见。
- `evidence/settings-panel/`：1280×900、900×640 包含原文章背景的完整面板，确认外边距、底部齿轮与布局。
- `evidence/settings-motion-probe/report.json`：首次进入和操作动画探测通过；设置工具页无需滚动叙事。
- `evidence/settings-motion/`：进入、选择书签、自动保存、切到快捷键、开关、切到关于；保留开始/中间/结束图与报告。
- `evidence/settings-mode-switch/`：340×876，实际点击六种方式并回到正文；保留开始/中间/结束图与报告，标题、剪藏按钮和分类位置保持一致，选中底板移动。
- `evidence/settings-pointer-stability.json`：原生指针实际点击完整宿主中的六种方式，1280×900 与 900×640 的宿主边框、原文标题、面板标题/按钮/分类、宿主与面板滚动位置采样最大偏移均为 0px。该报告是几何与滚动检查，不能替代录帧的动效观感。

三处基本动效为设置内容进入/分类切换时 200ms 的 4px 上移淡入、选择底色与开关滑块反馈、保存成功状态 220ms 淡入。沿用方式列表选中底板，减少动态效果时停用过渡。未安装 ffmpeg，因此保留三张阶段图，没有合成视频；原始逐帧序列已移除。

早期 `settings-switch-motion/` 的 304×616 录制点击会先被取证工具强制居中滚动，导致标题与按钮被顶起；该录制不作为产品稳定性证据。完整宿主 `settings-host-switch/` 的取证工具键盘步骤未进入 iframe，只有入场，亦不作为方式切换证据。方式动效使用新的独立面板录帧，完整宿主稳定性由真实指针检查与集成逐帧检查补充；没有声称获得完整宿主全部切换的视频。

## 验证

主 Agent 在最后一次实现修改后连续运行项目检查三次，每次全部通过、创建 11 个隔离模拟草稿：`evidence/settings-check-1.log`、`settings-check-2.log`、`settings-check-3.log`。

检查使用隔离 Chromium、真实扩展入口与 worker、本地模拟 HTTP 服务、实际采集与存储。仅剪贴板/截图的系统平台边界和一次设置写入失败按既有测试方式替换，不读写用户浏览器账号，也不向线上创建文章。

新增覆盖：齿轮打开实际 Chrome options 页面；自动保存与刷新读回；写入失败/重试与输入保留；设置导航键盘操作；快捷键开关与当前面板同步；减少动态效果；安全恢复默认；新网页默认值、已有草稿优先、最近方式、无选区回退；剪藏后打开/收起与成功页恢复不重复动作。每次模式更新过程逐动画帧比较标题、按钮、分类位置和滚动位置，通过后才恢复剪藏按钮。

原登录、六格输入、分类/标签、三标签上限、复制链接、六种采集、资源上传、草稿恢复、保存失败与重试、源标签页校验等检查继续通过。没有生产构建或部署。
