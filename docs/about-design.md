# 拾页：只保留关于页

> 以下记录为 0.5.1 历史流程精简。当前 0.5.4 使用面板内绿色装帧关于页，见 [面板内关于页](about-inline-design.md)。

日期：2026-10-10 · 版本：0.5.1

本轮是存量流程精简，视觉沿用既定暖白纸面、绿色、统一字体和直角分隔。用户只需要「关于拾页」，不需要通用或快捷键设置；以单一信息页呈现用途、版本、保存位置和标签上限，保留打开页息链接。

原流程：点击齿轮 → 默认通用设置 → 点击关于，2 次点击、1 次打开独立标签页；现在点击信息图标即得到关于，1 次点击、1 次打开独立标签页，不再作分类选择。计数以面板已打开且已登录为起点，不计算此前剪藏操作。理想路径就是入口直接显示所需信息。

移除通用/快捷键表单、侧栏导航、恢复默认、自动保存状态、写入失败和重试逻辑，以及对应的失效样式与模拟写入。保留版本、用途和主产品链接，没有用装饰说明填补空白。关于入口用自有圆圈信息图标，悬停与可访问名称均为「关于拾页」。生产继续使用 options_ui 与 openOptionsPage，内部 options/settings.* 文件名保留，以兼容既有入口。

该页只读，不修改登录、草稿或早期版本保存的偏好。原偏好解析保留兼容，剪藏切换稳定性修复保留；不混入采集、API 或后台重构。预览 `/about-preview` 为主入口，旧 `/settings-preview` 仍显示同一页。预览仅模拟版本和只读存储，生产不加载模拟脚本。
