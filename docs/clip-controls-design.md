# 拾页 0.4.0：剪藏方式、分类与标签

日期：2026-10-09。用户任务：去掉正文预览，提供更多实际剪藏方式，替换原生分类菜单，改善标签互动，统一图标，并采用直角框。

方向沿用既定纸白与绿色阅读工具。参考只读 clipper01 的类型列表、选中状态与框线；不复制其代码、品牌或官方素材。外层面板 400px、上下右 12px、全高保持；框与字段用直角，按钮和签条小圆角，统一自绘线条图标。登录依然是六格访问码，默认线上页息，无设置入口。

## 行为与接口

正文预览整块移除，保留当前网页的可编辑标题、来源和统计。剪藏流程是类型 → 分类/标签 → 保存，不增加预览确认步骤。页头和底部保存操作固定，中部独立滚动；矮视口收紧间距，文字不缩小。

| 方式 | 实际结果 |
| --- | --- |
| 网页正文 | 识别正文，保留图片/链接/排版，清理导航、广告与无关内容 |
| 整个网页 | 主文档文字、图片、导航和页脚转换为 Markdown；清理脚本、表单、隐藏内容与自身面板 |
| 纯文字 | 正文文字、链接与 Markdown 结构，无图片/封面 |
| 选中内容 | 当前网页选区转换为 Markdown；需先选中文字 |
| 书签 | 标题、摘要、原文链接 |
| 屏幕截图 | 保存动作触发当前可见区域 PNG，隐藏面板后捕获，上传到页息，保存图片与来源草稿 |

PageHush 现有文章 schema 已接受六种类型。复用 `GET /v1/topics`、`GET /v1/tags`、`POST /v1/assets` 与 `POST /v1/articles`，无需改动主项目或部署服务。截图 multipart 的 kind 在 file 前，携带扩展会话而非网页 Cookie；资源成功后用 coverAssetId 关联文章。截图前后核对窗口活动标签页与实际 URL；切换来源会拒绝捕获，失败也恢复面板。资源上传与文章保存分别失败时都保留输入，不自动重发。

分类菜单使用顶层浮层，按可用空间向上/下展开，带搜索、选中勾号、无结果、方向键/Home/End/Enter、Esc 和外部点击关闭。Esc 先关闭菜单，再关闭面板。加载失败禁用保存但保留登录；空分类延用保存时创建「学习」。

标签使用可删除签条，回车、逗号或粘贴批量确认；忽略大小写的重复标签，最多 10 个，每签最多 40 字。空输入时退格移除末签；也可点击已有页息标签。待输入文本、签条、标题和分类按来源网页暂存在浏览器会话，重开恢复；保存时确认尚未按回车的文本。已有标签接口失败不阻断手动添加。

## 取证与动效

真实扩展页面与后台逻辑由本地预览入口加载，预览接口使用隔离内容；截图不会调用生产 API。实际插件保存默认仍连接线上页息。取证全部使用 oil-ui-pro 的 shoot.mjs。

| 证据 | 路径（相对于 docs/evidence） |
| --- | --- |
| 原有基线 | side-panel/clip.png |
| 当前登录、剪藏、成功、保存失败，1280×900 | clip-controls/ |
| 矮/窄浏览器，900×640 与 360×740 | clip-controls-responsive/ |

## 独立评审与删减

一轮全新隔离的存量界面只读评审，不打分。评审看基线、全状态、200% 和动效，并实操搜索/键盘、398×616 矮面板、336×716 长标签换行/移除、菜单向上避让和保存流程。没有发现必须修复的可观察视觉问题；提出补保存主操作证据，已补保存阶段图，独立复核确认主操作证据缺口关闭。

采纳文案减法：标签占位符改为「添加标签」，删除重复「按回车留下」与「空格保留在标签中」；保留「回车或逗号成签」。此前的「剪藏预览」及预览字数整块删除。保存为草稿、截图范围与失败恢复说明继续保留。

主 Agent 连续三次运行 tests/check.mjs，结果均通过，各生成 9 份隔离草稿，记录 clip-controls-check-1.log、clip-controls-check-2.log、clip-controls-check-3.log。包含真实扩展后台、storage、内容提取和 HTTP；覆盖六种内容、登录/过期、分类搜索与空结果、签条去重/限额/输入恢复、保存失败/重新读取、并发保护、固定页头/底栏、窄窗口、菜单先处理 Esc、截图 multipart/面板隐藏恢复和来源变更拒绝。

截图捕获 API 需要真实工具栏手势，集成检查只替换这一平台边界返回 PNG；其余截图隐藏、上传、认证与文章保存保留真实链路。未用用户访问码向生产环境创建测试文章，未声称生产图片存储已验证。更新已安装浏览器扩展的自动操作被当前 URL 限制阻止，需要用户在扩展管理页重新加载 0.4.0。

本次未加入裁剪、标注、滚动长图、PDF/Gmail 专用采集：截图明确只保存可见区域，整页内容以可编辑 Markdown 保存，不复制网页 CSS。PNG 超过现有 5MB 限制会提示缩小窗口；服务器图片存储不可用时明确提示改用其他剪藏方式。正文远程图片链接保留，不批量下载上传。
